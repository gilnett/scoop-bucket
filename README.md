# scoop-bucket

Personal Scoop bucket for Windows CLI tools and utilities.

## Usage

### 1. Add this bucket

```powershell
scoop bucket add gilnett https://github.com/gilnett/scoop-bucket
```

### 2. Install packages

```powershell
scoop install wstrace
```

### 3. Update packages

```powershell
scoop update wstrace
```

## Available Packages

| Package | Description | Version |
| :--- | :--- | :--- |
| [`wstrace`](https://github.com/gilnett/wstrace) | High-performance zero-driver Windows system and API monitor in Rust | `0.2.2` |
